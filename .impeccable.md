## Design Context

### Users
MemeDrop is primarily for a single power user managing a personal meme stash. The user is saving reaction GIFs, short videos, and link-based media for their own later use, usually in a fast, repeatable workflow rather than a leisurely browsing session.

The main job to be done is to grab content from links fast, keep it accessible, and resend it quickly when needed. The product should reduce friction between discovery, saving, and re-sharing.

### Brand Personality
Minimal, sharp, utilitarian.

The interface should feel decisive and efficient rather than playful or sentimental. It should communicate competence, speed, and control, with just enough polish to make repetitive use satisfying.

### Aesthetic Direction
The visual tone should support a personal high-speed media tool rather than a social feed or collector showcase. Favor compact hierarchy, clear status visibility, strong affordance for primary actions, and layouts that optimize scan speed.

The app should feel modern and deliberate, but not soft, decorative, or trend-chasing. It should avoid novelty styling that slows recognition or makes core actions feel buried.

### Design Principles
1. Optimize for shortest path to action.
Every important screen should make save, find, and re-share feel immediate.

2. Make system state obvious.
Importing, ready, failed, and share-complete states should be legible at a glance.

3. Keep the interface lean.
Remove decorative clutter and anything that competes with media visibility or action clarity.

4. Reward repetition through precision.
The user is likely to use the app often, so interactions should feel tight, consistent, and fast rather than theatrical.

5. Treat the library as a tool, not a feed.
Browsing matters, but the product should prioritize retrieval and resend speed over entertainment-style discovery.
